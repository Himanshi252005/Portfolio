# Himanshi Rathore — Portfolio

A responsive portfolio for my work in data science, AI applications, analytics, and product experimentation.

**Live site:** https://himanshi252005.github.io/Portfolio/

## Featured projects

- Niveshak Saathi — bilingual investor-safety companion
- SaaS Pulse — synthetic customer analytics and churn dashboard
- A/B Testing & Product Experimentation — simulated experiment case study
- Multi-Agent Research System — AI-assisted research workflow
- AI Content Studio — full-stack editorial workspace
- Job Application Copilot — local job-search assistant

## Built with

HTML, CSS, and a small amount of vanilla JavaScript. The site works as a static GitHub Pages project. It uses DM Sans and Fraunces from Google Fonts, with local fallbacks.

## Preview locally

Open `index.html` in a browser, or serve the repository with any static web server. No build step is required.
